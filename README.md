# CSA1104 - Object-Oriented Analysis and Design (OOAD)

This repository contains the complete set of UML design models and architectural diagrams for the **CSA1104 Object-Oriented Analysis and Design** course (Exercises 01 to 25).

Each exercise contains standard UML models exported in XMI format (`.xmi`), covering:
1. **Use Case Diagram** (`*_1_UseCase.xmi`) &ndash; Functional requirements and actor interactions
2. **Class Diagram** (`*_2_Class.xmi`) &ndash; Static structure, attributes, methods, and relationships
3. **Activity Diagram** (`*_3_Activity.xmi`) &ndash; Business logic, workflow, and operational flow
4. **Sequence Diagram** (`*_4_Sequence.xmi`) &ndash; Object interactions and message exchanges over time
5. **Component Diagram** (`*_5_Component.xmi`) &ndash; High-level software components and dependencies
