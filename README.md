# CSA1104 - Object-Oriented Analysis and Design (OOAD)

This repository contains the complete set of UML design models and architectural diagrams for the **CSA1104 Object-Oriented Analysis and Design** course (Exercises 01 to 40).

Each exercise contains standard UML models exported in XMI format (`.xmi`), covering:
1. **Use Case Diagram** (`*_UseCase.xmi`) &ndash; Functional requirements and actor interactions
2. **Class Diagram** (`*_Class.xmi`) &ndash; Static structure, attributes, methods, and relationships
3. **Activity Diagram** (`*_Activity.xmi`) &ndash; Business logic, workflow, and operational flow
4. **Sequence Diagram** (`*_Sequence.xmi`) &ndash; Object interactions and message exchanges over time
5. **Component Diagram** (`*_Component.xmi`) &ndash; High-level software components and dependencies
